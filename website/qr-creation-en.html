Create QR Codes for Different Types of Data

Learn about the QR code creation feature planned for Scanix QR and the different types of information that may be converted into scannable QR codes.

What Is This Feature?

The planned feature is intended to convert different types of data into QR codes. Another phone may then scan the code and handle its contents according to the data format and the applications available on that device.

Important: QR code creation is not currently available in the existing version of Scanix QR. The information below describes the planned scope of the feature, and the final details may change during implementation.

Planned Data Types

1

Text and Numbers

Convert plain text, notes, numbers, identifiers, and reference codes into QR codes that can be scanned to read their contents.

2

Website and Internet Links

Convert website addresses, web pages, and direct links into QR codes to make opening them easier on compatible devices.

3

Maps and Geographic Locations

Create codes containing geographic coordinates or a map link to help people find a specified place.

4

Wi-Fi Networks

Include a Wi-Fi network name, password, and security type so compatible devices can read the network details and assist with connecting.

5

Contacts

Include information such as a person's name, phone number, email address, and other contact details to make them easier to read and save.

6

Phone Numbers and Messages

Create codes containing phone numbers or text message details, depending on the supported format and device compatibility.

7

Email

Include an email address and potentially a subject and message body, according to the format selected for implementation.

8

Events and Appointments

Include event or appointment details such as a title, date, time, and location, depending on the formats supported by the feature.

9

Other Data Types

Additional data types and use cases may be considered in the future based on requirements and QR code format compatibility.

How Will It Work?

Once implemented, the feature is intended to let users select a data type, enter the required information, and convert it into a suitable QR code. The resulting code could then be scanned by compatible devices and applications.

The result will depend on the contents of the code. It may display text, open a link, prepare contact information, or help locate a geographic position.

Passwords and Private Information

A QR code may contain information that anyone who scans it can read, including Wi-Fi credentials embedded in the code. Avoid sharing codes containing private information with unintended recipients.

Current Status

This page describes a planned future feature. The data types listed here are not necessarily supported in the current version. The final supported formats and details will be clarified when the feature is implemented.
